## Overview

Try to guess a randomly generated number between **1 and 10**. The project demonstrates basic JavaScript logic, random number generation, and handling user input in the browser.

## Features

- Generates a random number from 1 to 10
- Accepts a player's guess
- Validates user input
- Provides a simple browser-based game experience

## Technology stack

- **HTML** — game interface
- **CSS** — visual styling
- **JavaScript** — randomization and game logic

## Run locally

```bash
git clone https://github.com/rlaharira/number-guessing-game.git
cd number-guessing-game
```

Open `index.html` in a modern browser. No dependencies or build tools are needed.
